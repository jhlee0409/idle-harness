# Examples — Real Apps Built by Idle Harness

Real applications generated by Idle Harness from single-sentence prompts.

Each example below was autonomously planned, implemented, and quality-tested by the three-agent pipeline (Planner, Generator, Evaluator) with zero human intervention after the initial prompt.

## Mystic Arcana — AI Tarot Reading App

**Prompt:**
> A tarot reading web app with card-draw animations and AI interpretations

**What was generated:**

A fully immersive tarot reading application with a mystical dark theme, 3D card animations, and an AI interpretation engine — delivered across four iterative sprints.

- **Frontend:** React + Vite + Tailwind CSS v4 with custom typography (Cinzel, Lora, Inter)
- **Backend:** FastAPI (Python) + SQLite with a full 78-card Major and Minor Arcana deck
- **16 components** including animated particle background, glass-morphism navigation, and a canvas-based share card generator

**Features built autonomously:**

- Three spread types: Single Card, Three-Card, and Celtic Cross (10 cards)
- Intention setting with category chips (Love, Career, Personal Growth, General)
- 3D card-flip animation with golden glow and sparkle particle effects
- AI interpretation engine with 78 unique card meanings, position-aware narratives, and context from the user's question
- Typewriter streaming effect for interpretation text
- Reading history with personal reflections, favorites, and full detail views
- Card Codex — browsable encyclopedia of all 78 tarot cards with search and filtering
- Daily Card ritual with streak tracking
- Mood and energy tracker (8 moods) with an analytics/insights dashboard
- Ambient soundscapes via Web Audio API (Crystal Resonance, Mystic Rain, Ethereal Silence)
- Shareable reading cards — canvas-generated PNG images and share links with public read-only views

## LinkVault — AI-Powered Personal Bookmark Manager

**Prompt:**
> An AI-powered personal bookmark manager

**What was generated:**

A full bookmark management application that uses built-in heuristic NLP to auto-tag and summarize saved links — delivered across four iterative sprints.

- **Frontend:** React + Vite + Tailwind CSS with dark-mode glass-morphism design
- **Backend:** FastAPI (Python) + SQLite with a built-in heuristic NLP engine (no external API keys)
- **17 components** including animated charts, import/export modals, and keyboard shortcut overlays

**Features built autonomously:**

- URL capture with automatic metadata fetching (title, thumbnail, favicon, description)
- AI auto-tagging (1-3 contextual tags per bookmark) and AI summary generation
- Real-time search (Cmd/Ctrl+K) across titles, URLs, tags, and summaries with highlighting
- Slide-in detail panel with editable title, personal notes, and AI summary
- Favorites and pinning (up to 5 pinned bookmarks in a top section)
- Collections — create, rename, delete named groups with an "Uncategorized" smart filter
- Browser bookmark import (Netscape HTML format) with progress indicator and queued AI processing
- Full library export as JSON with all metadata
- Reading stats dashboard with animated bar and donut charts, top domains, and summary metrics
- Keyboard-first navigation with a help overlay listing all shortcuts

## What You Can Build

Idle Harness generates full-stack web applications from short natural-language prompts. Here are examples of good prompts:

**Productivity and tools:**
- "A personal finance tracker with spending categories and monthly charts"
- "A recipe finder that filters by dietary restrictions and cooking time"
- "A habit tracker with streaks, daily check-ins, and weekly progress graphs"

**Creative and social:**
- "A collaborative mood board where users can drag and arrange images and text"
- "A poetry generator that creates verses from user-selected themes and styles"
- "A movie watchlist app with ratings, reviews, and recommendation suggestions"

**Knowledge and learning:**
- "A flashcard study app with spaced repetition and quiz modes"
- "A personal wiki for organizing notes with bidirectional linking"
- "A language vocabulary builder with daily practice and progress tracking"

**Data and dashboards:**
- "A weather dashboard that shows forecasts, historical trends, and alerts for saved locations"
- "A fitness log with exercise tracking, personal records, and workout charts"
- "A reading list manager that tracks books, progress, and generates reading statistics"

Each prompt produces a React + Vite frontend, FastAPI + SQLite backend, and a polished UI with features the Planner agent derives from the prompt. The adversarial evaluation loop ensures the generated application actually works end-to-end.
